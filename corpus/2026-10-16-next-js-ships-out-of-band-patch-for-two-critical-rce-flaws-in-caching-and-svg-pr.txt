TITLE: Next.js Ships Out-of-Band Patch for Two Critical RCE Flaws in Caching and SVG Processing
SOURCE: https://thehackernews.com/2026/10/nextjs-ships-out-of-band-patch-for-two.html
---
Next.js released an&nbsp;out-of-band security update&nbsp;on October 14 that fixes two critical flaws allowing unauthenticated remote code execution, along with a high-severity denial-of-service flaw.

One code-execution flaw is in React Server Components, and the other in librsvg, the open-source library Next.js uses through the&nbsp;sharp&nbsp;package to handle SVG images.
